### 产品需求

# 父任务完成时连带完成子任务

## 1. 背景与问题

项目经理把父任务改成 Done 或延期完成时，子任务要逐个再改一次。需要在这次操作里询问是否把同一项目的子树一并改为 Done。

## 2. 目标与非目标

### 2.1 目标

- 项目经理把父任务改为 Done 或延期完成时，可以选择是否把符合条件的子任务改为 Done。
- 取消、延期完成、挂起、带阻断标签的任务，以及这些任务下面的子任务，保持原状态。
- 未结束的阻断子任务仍然阻止父任务完成。

### 2.2 非目标

- 不修改关联任务。
- 不把子任务改成延期完成。子任务的目标状态只有 Done。
- 产品、开发、测试完成父任务时，不提供连带完成。
- 不改变未启用轻量工作流的项目。

## 3. 用户与使用场景

| 用户 / 角色      | 使用场景                                           | 核心诉求                                              |
| ---------------- | -------------------------------------------------- | ----------------------------------------------------- |
| 项目经理         | 把父任务改为 Done 或延期完成，子树里还有未完成任务 | 一次确认后，该完成的子任务改为 Done，不该动的保持原状 |
| 产品、开发、测试 | 按原有流转把父任务改为 Done                        | 只改父任务，不出现连带弹窗                            |

## 4. 范围

### 4.1 包含范围

- 已启用轻量工作流的项目。
- 同一项目内、以父子关系连起来的整棵子树。
- 项目经理发起的、目标为 Done 或延期完成的状态修改。

### 4.2 不包含范围

- 关联任务（重复、关联、阻塞、前后置等关系）。
- 其他项目中的任务。
- 未启用轻量工作流的项目。
- 父任务改到 Done、延期完成以外的状态。

## 5. 产品方案

### 5.1 用户流程

1. 项目经理把某个任务改为 Done 或延期完成。
2. 若它的直接子任务里仍有带阻断标签、且状态不是 Done、延期完成或取消的任务，本次修改失败。不弹窗，不改任何子任务。沿用现有提示：仍有未完成的阻断子任务，主任务不能完成。
3. 若没有可改为 Done 的子任务，不弹窗。父任务按本次选择完成。
4. 若有可改的子任务，弹窗询问是否把子任务一并改为完成。
5. 选「是」：父任务进入本次选择的 Done 或延期完成；符合条件的子任务改为 Done。
6. 选「否」：只完成父任务，子任务保持原状态。

### 5.2 功能与业务规则

| 编号   | 功能 / 规则        | 优先级 | 说明                                                                                                                                               |
| ------ | ------------------ | ------ | -------------------------------------------------------------------------------------------------------------------------------------------------- |
| PR-001 | 触发条件           | P0     | 仅项目经理，且目标状态是 Done 或延期完成                                                                                                           |
| PR-002 | 连带范围与目标状态 | P0     | 同一项目的整棵子树。被改动的子任务进入 Done，不进入延期完成                                                                                        |
| PR-003 | 拒绝连带           | P0     | 选「否」后父任务仍完成，子任务不变                                                                                                                 |
| PR-004 | 跳过的状态         | P0     | 取消、延期完成、挂起的任务本身不改，其下整枝也不改。已是 Done 的任务本身不改；它下面不在跳过枝上的任务仍改为 Done。延期中不在跳过范围内，改为 Done |
| PR-005 | 阻断标签           | P0     | 带阻断标签的任务本身不改，其下整枝也不改                                                                                                           |
| PR-006 | 关联任务           | P0     | 不因父任务完成而修改                                                                                                                               |
| PR-007 | 其他角色           | P0     | 产品、开发、测试不看到弹窗，也不连带修改子任务                                                                                                     |
| PR-008 | 阻断拦截           | P0     | 保留现有规则：主流程上，直接子任务带阻断标签且未到 Done、延期完成或取消时，父任务不能完成                                                          |
| PR-009 | 无可改子任务       | P0     | 不弹窗                                                                                                                                             |

从父任务往下逐层看。某一层属于取消、延期完成、挂起或带阻断标签时，停止这一枝。其他子任务继续判断。

### 5.3 交互、状态与文案

弹窗只在 PR-001 成立、PR-008 未拦截、且子树中至少有一个可改为 Done 的任务时出现。

- 说明：是否将子任务一并改为完成。
- 按钮：「是」执行连带；「否」只完成父任务。
- 关闭弹窗与选「否」相同：父任务完成，子任务不变。

其他角色的状态选择器保持现有流转，不增加此弹窗。

## 6. 异常与边界

| 场景                                               | 期望处理                                                                               | 用户可见反馈               |

| 直接子任务中有未结束的阻断任务                     | 父任务不完成，子任务都不改                                                             | 现有阻断提示               |
| 子树中有阻断标签，但它不是会拦住父任务的直接子任务 | 父任务可以完成；该任务及其下级不改                                                     | 弹窗仍按其余可改子任务出现 |
| 子任务已是 Done                                    | 该任务不改；其下级按 PR-004 继续判断                                                   | 无单独提示                 |
| 子任务在其他项目                                   | 不改                                                                                   | 无单独提示                 |
| 只有关联关系、没有父子关系                         | 不改                                                                                   | 无弹窗                     |
| 连带改子任务时其中一条保存失败                     | 已成功改成 Done 的子任务不回滚要求之外的状态；失败的子任务保持原状态，并告知哪些没改成 | 列出未改成的子任务         |

最后一行是起草时补上的失败反馈，见变更记录。若要整批同时成功或同时失败，需另作决定。
